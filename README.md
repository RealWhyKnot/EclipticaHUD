# EclipticaHUD

Boss and damage HUD for the VRChat world Ecliptica. It reads your VRChat log and shows up as a desktop panel and a SteamVR overlay on your left controller.

Ecliptica had a big update and we're still catching the HUD up to it.

Download it from [Releases](https://github.com/RealWhyKnot/EclipticaHUD/releases). To build it yourself you need MSVC, CMake and LLVM, then run `cargo build --release`.
